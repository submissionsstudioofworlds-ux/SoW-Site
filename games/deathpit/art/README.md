# Dropping your own art in

Everything in the game is currently drawn from hand-authored character grids in
`sprites.js`. Those are an approximation of the model sheets — good enough to
read as the right characters, but not the same thing as the real art.

This folder is the override. Put a PNG here, list it in `manifest.json`, and the
game uses it instead of the grid art at boot, with no code change. Anything not
listed simply keeps using the built-in art.

The manifest is what keeps this opt-in — without it the game would fire a
request for all twelve sheets on every load and fill the console with 404s.

`art/manifest.json` is a plain list of the files you have added:

```json
["bob-idle.png", "bob-run.png", "gremlin.png"]
```

## Naming and frame counts

| File | Frames | What it is |
| --- | --- | --- |
| `bob-idle.png` | 2 | Standing, breathing |
| `bob-run.png` | 4 | Run cycle: contact, pass, contact, pass |
| `bob-jump.png` | 1 | Rising |
| `bob-fall.png` | 1 | Falling |
| `bob-swing.png` | 3 | Dagger: wind-up, thrust, recovery |
| `bob-stab.png` | 1 | Down-stab (the pogo attack) |
| `bob-hurt.png` | 1 | Recoiling after a hit |
| `gremlin.png` | 2 | Walk cycle |
| `grub.png` | 2 | Cave crawler walk |
| `bat.png` | 2 | Wings up, wings down |
| `pod.png` | 2 | Sporepod shut, sporepod spitting |
| `shroom.png` | 2 | Bounce shroom at rest, squashed |

## Rules for every sheet

- **One horizontal strip** of equal-width frames, in the order listed above.
  A 4-frame run at 30px wide is a single 120×N PNG.
- **Face right.** The left-facing copy is generated by mirroring, so you only
  draw one direction.
- **Transparent background.**
- **Feet on the bottom row.** Frames are anchored by their centre and
  bottom-aligned to the collision box, so empty rows under the feet will make
  the character hover.
- **Any pixel size.** Art taller than the hitbox simply overhangs it — that is
  already true of Bob, whose head sticks well above his collision box. The
  hitboxes are fixed in `game.js` (`PLAYER_W` / `PLAYER_H`, and `w` / `h` on
  each enemy constructor) and are deliberately smaller than the sprites.

## Checking it worked

Load the game with the console open. Any sheet that was picked up is listed:

```
Death Pit: using PNG art for art/bob-idle.png, art/bob-run.png
```

A file listed in the manifest but missing from disk warns instead:

```
override listed but missing: art/gremlin.png
```

## What is not overridable this way

The Plancktopus is drawn procedurally in `game.js` rather than from sprites,
because it breathes, slumps, opens its maw and grows a variable number of arms.
Its look is controlled by the `BOSS_COL` palette and the `bossHalfWidth()`
profile curve near the top of the boss section — changing colours there is
cheap; changing its shape means editing that curve.
